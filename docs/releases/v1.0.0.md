# BobAPI Tool v1.0.0

First Windows x64 release of BobAPI Tool.

- Manage ChatGPT/Codex and Claude Code API endpoint and API key settings.
- Test API connectivity and fetch available models from compatible providers.
- Search model lists or enter a custom model ID.

## Downloads

- **Windows installer (recommended):** `BobAPI-Tool-v1.0.0-Windows-x64-Setup.exe`
- **Windows standalone:** `BobAPI-Tool-v1.0.0-Windows-x64-Standalone.zip`
- **SHA-256 checksums:** `SHA256SUMS.txt`

Requires Windows 10/11 x64 and Microsoft Edge WebView2 Runtime. The installer
can install the runtime if it is missing (internet access required).
The standalone ZIP uses the normal user profile for configuration.

This release is not code-signed, so Windows may show an unknown-publisher
warning. Automatic updates are not configured; download updates from this
repository's Releases page.

Validation: TypeScript typecheck, 10 Rust unit tests, and production Tauri build.
